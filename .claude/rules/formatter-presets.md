Built-in external formatter presets live in `src/config/formatter_presets.rs`.

- Keep `PRESETS` metadata and `formatter_preset_names()` in sync.
- Preset names are free-form strings in config; schema regeneration is not
  required for preset name additions.
- `docs/reference/_formatter-presets-details.qmd` is generated by `build.rs`;
  never hand-edit it.
- For stdin tools that need filename hints, use `{}` args placeholders and
  ensure language extensions are mapped.
- Add focused preset-resolution tests for new/changed presets.
